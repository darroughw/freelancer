# Colors

Generated from a single JSON source, [`tokens/color.json`](https://github.com/darroughw/freelancer/blob/main/tokens/color.json),
via [Style Dictionary](https://styledictionary.com) (`npm run build:tokens`).
That one file fans out to three generated outputs — Sass variables in
`app/styles/_theme.scss`, CSS custom properties in `app/styles/tokens.css`,
and a typed JS object in `app/styles/tokens.ts` — so a color only needs to
change in one place. None of the three generated files should be hand-edited;
they're overwritten on every build.

This is the site's original palette — five accent hues plus ink and cream,
unchanged in value since before the typesafe.ai-inspired visual refresh.
What changed in that redesign was everything built *with* the palette
(window-chrome cards, hard borders, the masthead's full-bleed hero gradient),
not the colors themselves.

## Notes

- **`red-text`** is a darker variant of `red` for small/normal-weight text on
  light backgrounds — `red` itself only clears WCAG AA contrast at large text
  sizes.
- **`red-deep`** is a darker variant of `red` for use as a background behind
  cream text — `red` itself only gives cream text ~4.0:1 contrast, below the
  4.5:1 AA threshold.
- The palette is defined in `oklch()` rather than hex so lightness and chroma
  stay perceptually consistent across hues.

## Gradients

Two gradients, both referencing the CSS custom properties directly (not
resolved values), both ink-text-adjacent:

    <code>gradient.hero</code>
  </div>

- **`gradient.tape`** is the full five-stop sunset (mustard → orange → red →
  red-deep → plum), used where nothing is printed on top of it (the header's
  bottom border-image).
- **`gradient.hero`** is a narrower, text-safe subset (mustard → orange → red
  only) for the masthead's full-bleed hero background, which has the ink
  headline sitting directly on top. `red-deep` and `plum` are deliberately
  excluded: computed contrast of ink text against each stop is mustard 8.95:1,
  orange 6.96:1, red 3.74:1 (clears the 3:1 large-text floor, the tightest
  margin in the gradient), red-deep 2.67:1, plum 1.96:1 — the last two fail
  outright, which is why the hero gradient stops at red.
