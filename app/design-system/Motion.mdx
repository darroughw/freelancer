# Motion & Shape

Like Foundations → Spacing & Layout, these are values surveyed directly out
of `app/styles/*.scss` rather than a scale invented after the fact.

anything meant to read as a button or tag. Nothing in between.

## The one animation: `crt-flicker`

The contact section's CRT-styled panel runs a 6-second looping
`@keyframes crt-flicker` on `filter: brightness()`, mimicking an old tube
monitor's uneven refresh rather than a smooth pulse:

```css
@keyframes crt-flicker {
  0%, 92%, 100% { filter: brightness(1); }
  93% { filter: brightness(1.12); }
  94% { filter: brightness(0.9); }
  95% { filter: brightness(1.04); }
}
```

The flicker sits in the last 8% of each cycle rather than being spread
evenly, so it reads as an irregular glitch instead of a metronomic pulse.

## `prefers-reduced-motion`

A single global override in `_a11y.scss` — not per-component opt-outs — kills
every transition and animation site-wide, including `crt-flicker`, when the
user has motion reduction enabled at the OS level:

```css
@media (prefers-reduced-motion: reduce) {
  * {
    transition-duration: 0.01ms !important;
    animation-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
