# Motion & Shape

Like Foundations → Spacing & Layout, these are values surveyed directly out
of `app/styles/*.scss` rather than a scale invented after the fact.

Six values in practice, at two ends of a spectrum: small functional radii
(4–12px) for cards and inputs, and full pill/circle radii (50%, 100px) for
anything meant to read as a button or tag. Nothing in between.

## `prefers-reduced-motion`

No `@keyframes` animation exists in the stylesheets currently (the contact
section's photo treatment is a static halftone/duotone filter, not an
animated one). A single global override in `_a11y.scss` still kills every
transition site-wide — not per-component opt-outs — when the user has motion
reduction enabled at the OS level, ready to catch any animation added later:

```css
@media (prefers-reduced-motion: reduce) {
  * {
    transition-duration: 0.01ms !important;
    animation-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
