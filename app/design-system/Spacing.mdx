# Spacing & Layout

There's no formal spacing scale in this codebase — values below are what's
actually used across `app/styles/*.scss`, surveyed directly rather than
invented after the fact.

## Breakpoint

There is exactly **one** responsive breakpoint in the whole site:

<div style={{ fontFamily: "'Space Mono', monospace", fontSize: 14, background: "#00000010", padding: "12px 16px", borderRadius: 8, display: "inline-block" }}>
  @media (max-width: 640px)
</div>

Below 640px, multi-column layouts (the work-card grid, the case-study image
gallery, the pager) collapse to a single column.

## Spacing scale in use

Discrete `px` values found in `gap` / `margin` / `padding` declarations,
smallest to largest:

<div style={{ display: "flex", flexDirection: "column", gap: 6, fontFamily: "'Space Mono', monospace", fontSize: 12 }}>
  {[3, 4, 5, 6, 7, 8, 9, 10, 12, 14, 15, 16, 20, 24].map((px) => (
    <div key={px} style={{ display: "flex", alignItems: "center", gap: 10 }}>
      <span style={{ width: 32, textAlign: "right" }}>{px}px</span>
      <div style={{ width: px * 4, height: 14, background: "#d1502e", borderRadius: 2 }} />
    </div>
  ))}
</div>

## Fluid section padding

Larger, section-level padding is set with `clamp(min, preferred, max)` so it
scales smoothly between mobile and desktop rather than jumping at the
breakpoint. A representative sample of the patterns in use:
