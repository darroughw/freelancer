# Spacing & Layout

There was no formal spacing scale in this codebase for a long time — the
breakpoint and the discrete scale below started as values surveyed directly
out of `app/styles/*.scss`, rather than invented up front. They're now
formalized as real tokens in
[`tokens/spacing.json`](https://github.com/darroughw/freelancer/blob/main/tokens/spacing.json),
generated via [Style Dictionary](https://styledictionary.com) the same way as
[Colors](?path=/docs/foundations-colors--docs) and
[Typography](?path=/docs/foundations-typography--docs). A new
<code>layout.container</code> token (<code>$container-width</code> /
<code>--container-width</code> / <code>tokens.spacing.container</code>,
<code>1240px</code>) is consumed by the masthead as of the typesafe.ai-inspired
redesign, but the rest of `app/styles/*.scss` still hasn't been rewired to
consume the generated `$space-*`/`$breakpoint-mobile`/`$fluid-*` variables, so
this page documents what's actually hardcoded in those files today. The
**Content widths** table at the bottom is intentionally not tokenized beyond
that one exception — those are one-off values tied to specific selectors, not
a reusable scale.

## Breakpoints

Three breakpoints, all tokens in <code>tokens/spacing.json</code>
(<code>$breakpoint-{'*'}</code> / <code>--breakpoint-{'*'}</code> /
<code>tokens.spacing.breakpoint{'*'}</code>). Media queries in the partials still
write the values out literally, since Sass variables are fine there but CSS
custom properties can't be used inside `@media`.

One more, untokenized: the header shrinks its name extrusion and hides the
status badge at `760px`, the point where the badge starts crowding the name.

## Spacing scale in use

Discrete `px` values found in `gap` / `margin` / `padding` declarations,
smallest to largest — each is token <code>spacing.N</code>, generated as
<code>$space-N</code> / <code>--space-N</code> / <code>tokens.spacing.space["N"]</code>:

<div style={{ display: "flex", flexDirection: "column", gap: 6, fontFamily: "'JetBrains Mono', monospace", fontSize: 12 }}>
  {[3, 4, 5, 6, 7, 8, 9, 10, 12, 14, 15, 16, 20, 24].map((px) => (
    <div key={px} style={{ display: "flex", alignItems: "center", gap: 10 }}>
      <span style={{ width: 32, textAlign: "right" }}>{px}px</span>
      <div style={{ width: px * 4, height: 14, background: "#cb473f", borderRadius: 2 }} />
    </div>
  ))}
</div>

## Fluid section padding

Larger, section-level padding is set with `clamp(min, preferred, max)` so it
scales smoothly between mobile and desktop rather than jumping at the
breakpoint. A representative sample of the patterns in use, tokenized as
<code>fluid.sm</code> through <code>fluid.xxl</code> (Sass <code>$fluid-sm</code>
through <code>$fluid-xxl</code>, CSS <code>--fluid-sm</code> through
<code>--fluid-xxl</code>, TS <code>tokens.spacing.fluid</code>):

## Bento grid spacing

Home page sections are bento grids: a 14px gap between tiles, tiles padded
`20px 24px` (story and contact tiles a little more), and the grid itself
inset with `fluid.sm`. Full grid spec in
[Patterns → Bento Grid](?path=/docs/patterns-bento-grid--docs).
