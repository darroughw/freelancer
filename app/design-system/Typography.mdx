# Typography

Three font families, loaded via Google Fonts in `app/layout.tsx`. Families,
weights, and the type scale below are generated from
[`tokens/typography.json`](https://github.com/darroughw/freelancer/blob/main/tokens/typography.json)
via [Style Dictionary](https://styledictionary.com) (`npm run build:tokens`)
— see [Foundations → Colors](?path=/docs/foundations-colors--docs) for how
that pipeline works. The scale tokens are consumed directly by every
`app/styles/*.scss` partial (`font: 700 $scale-paper-sm $paper-font`, etc.) —
each step's `comment` in `tokens/typography.json` documents which components
use it and why. The weight tokens aren't consumed yet (partials still
hardcode `font-weight` per rule); they're available as `$weight-*` Sass
variables, `--weight-*` CSS custom properties, and `tokens.typography.weight.*`
in TS for future use.

## Paper — `$paper-font`

`'Archivo', -apple-system, sans-serif` — body copy, form fields, and most UI
text. Used at weights 400–800 depending on emphasis.

<Typeset
  fontFamily="'Archivo', -apple-system, sans-serif"
  fontWeight={400}
  fontSizes={[11, 13, 15, 18]}
  sampleText="The quick brown fox jumps over the lazy dog."
/>

<Typeset
  fontFamily="'Archivo', -apple-system, sans-serif"
  fontWeight={700}
  fontSizes={[13, 15]}
  sampleText="The quick brown fox jumps over the lazy dog."
/>

## Head — `$head-font`

`'Archivo Black', 'Archivo', sans-serif` — display headings, always set at
weight 900. Sized fluidly with `clamp()` for large hero/section titles. The
four largest steps (`xl`/`2xl`/`3xl`/`4xl`) stay distinct rather than
collapsing into one — they carry real page-type hierarchy (masthead >
contact > case study), not unmanaged sprawl. `4xl` (120px) is the masthead
headline size added for the typesafe.ai-inspired redesign, uppercase and
tight-tracked — see Letter-spacing below.

<Typeset
  fontFamily="'Archivo Black', 'Archivo', sans-serif"
  fontWeight={900}
  fontSizes={[16, 18, 22, 28, 44, 56, 64, 120]}
  sampleText="Sample heading"
/>

## Mono — `$mono-font`

`'JetBrains Mono', monospace` — section labels, meta text, tags, tabular
data, and window-chrome title bars. Almost always uppercase and
letter-spaced in context. Swapped from Space Mono in the redesign — same
loading mechanism (a plain `<link>` tag in `app/layout.tsx`, not `next/font`),
chosen to read closer to a real terminal face.

<Typeset
  fontFamily="'JetBrains Mono', monospace"
  fontWeight={600}
  fontSizes={[10, 11, 12, 13]}
  sampleText="SECTION LABEL · META INFO"
/>

## Letter-spacing

Tracking is applied selectively, not as a blanket rule — it's what makes
small uppercase mono labels readable, so it clusters there:

<table>
  <thead>
    <tr><th>Value</th><th>Typical use</th></tr>
  </thead>
  <tbody>
    <tr><td><code>0.03em</code>–<code>0.05em</code></td><td>Body-adjacent labels (case-study meta, stat labels)</td></tr>
    <tr><td><code>0.08em</code>–<code>0.1em</code></td><td>Small uppercase mono labels (nav pills, section eyebrows, tags)</td></tr>
    <tr><td><code>-0.02em</code></td><td>Negative tracking: large uppercase display headings (the masthead title), where default tracking reads slightly loose at big sizes</td></tr>
  </tbody>
</table>
